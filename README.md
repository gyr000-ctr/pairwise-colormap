# pairwise-colormap

## 题面（可直接粘贴）

色带映射 + 感知均匀插值。约束：量化为 N 级且单调；越界 clamp；必须在 OKLab 空间插值并与 sRGB 直插可区分；LUT 与解析求值差 ≤1e-6；非单调色带报错；级数非法报错；10 万次查表不超过 100 ms；并发安全。验收：python -m pytest tests -q -k colormap。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 10 万次查表耗时
- 并发
- 非有限输入
- 停靠点上限
- 级数边界

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线）。
